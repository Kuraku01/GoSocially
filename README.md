# GoSocially - Invite-Only Social Messaging Platform

A comprehensive invite-only social messaging system built with PHP and MySQL. Features include secure authentication, social networking capabilities, privacy controls, and comprehensive moderation tools.

## Features

### Core Platform
- **Invite-Only Registration**: Users can only join with valid invite codes generated by existing members
- **Secure Authentication**: Password hashing, CSRF protection, session security, and rate limiting
- **Private Messaging**: Real-time one-on-one messaging with read receipts and permission controls
- **User Management**: Admin, moderator, and user roles with appropriate permissions
- **Modern Dashboard**: Responsive design with conversation management and user directory
- **Invite Code System**: Generate, track, and manage invitation codes with expiration

### Social Features
- **Profile Management**: Complete user profiles with customizable privacy settings
- **Follow System**: Follow/unfollow users with mutual relationship tracking
- **Messaging Permissions**: Control who can message you (everyone/mutuals only/approved only)
- **User Restrictions**: Block specific users from messaging you
- **Approved Lists**: Create whitelists of users who can always message you

### Presence & Activity
- **Real-time Status**: Active, busy, and invisible presence indicators
- **Online Status**: Show/hide your online status to other users
- **Visual Indicators**: Color-coded presence status throughout the interface
- **Privacy Controls**: Fine-tuned control over who can see your activity

### Safety & Moderation
- **User Reporting**: Comprehensive reporting system for inappropriate behavior
- **Admin Dashboard**: Professional moderation interface with statistics and analytics
- **Moderation Tools**: Timeout and ban functionality with customizable durations
- **Report Management**: Track and resolve user reports with detailed notes
- **Security Logging**: Complete audit trail of all moderation actions

## Requirements

- PHP 7.4+ with MySQLi extension
- MySQL 5.7+ database
- Apache or Nginx web server
- Modern web browser with JavaScript enabled

## Installation

### 1. Database Setup

Create a MySQL database and import the schema:

```sql
-- Create database
CREATE DATABASE gosocially;

-- Import schema
mysql -u username -p gosocially < database/schema.sql

-- Import seed data (includes test accounts)
mysql -u username -p gosocially < database/seed_data.sql
```

### 2. Configuration

Edit `config/database.php` and update your database credentials:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'gosocially');
define('DB_USER', 'your_db_username');
define('DB_PASS', 'your_db_password');
```

### 3. File Permissions

Ensure the web server can write to necessary directories:

```bash
chmod 755 .
chmod 644 *.php *.css *.js
chmod -R 755 css/ js/ includes/ config/ api/
```

### 4. Web Server Configuration

#### Apache (.htaccess)

```apache
RewriteEngine On
# Block access to config and includes directories
RewriteRule ^(config|includes|database)/ - [F,L]
# Handle pretty URLs (optional)
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php [QSA,L]
```

#### Nginx

```nginx
location ~ /(config|includes|database)/ {
    deny all;
}
location ~ \.php$ {
    fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
    fastcgi_index index.php;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}
```

## Usage

### First Login

1. Navigate to `http://yourdomain.com` in your browser
2. Login with any of the test accounts above
3. You'll be redirected to the dashboard

### Generating Invite Codes

1. From the dashboard, click "Generate New Invite" in the sidebar
2. Copy the generated 32-character invite code
3. Share this code with people you want to invite

### Registration with Invite Code

1. Click "Register with Invite Code" on the login page
2. Fill in the registration form with a valid invite code
3. After successful registration, you can log in immediately

### Sending Messages

1. From the dashboard, select a user from the "All Users" list
2. Users can only message others based on privacy settings and mutual relationships
3. Type your message and press Enter or click Send
4. Messages appear in real-time with read receipts
5. If messaging is restricted, you'll see a clear explanation why

### Profile & Privacy Settings

1. Click "Profile Settings" in the dashboard header
2. Configure your privacy preferences:
   - Who can message you (everyone/mutuals only/approved only)
   - Show/hide your online status
   - Allow or decline follow requests
   - Set your presence status (active/busy/invisible)
3. Manage your approved messaging list for "approved only" mode

### Following Users

1. In the user directory, click "Follow" next to users you want to follow
2. Mutual followers can message each other regardless of privacy settings
3. View your followers and following counts on your profile
4. Mutual relationships are marked with a "Mutuals" indicator

### Managing Restrictions

1. From your profile settings, add users to your approved messaging list
2. Users you follow will appear in conversations based on their privacy settings
3. Messaging restrictions are automatically enforced across the platform

### Reporting Users (For All Users)

1. Click "Report User" in any user interaction area
2. Select the reason for reporting (harassment, spam, inappropriate content, etc.)
3. Provide a detailed description of the issue
4. Submit the report for admin review
5. You can track your report status in your reporting history

### Admin Dashboard (For Admins/Moderators)

1. Access `/admin.php` when logged in as admin or moderator
2. View pending reports and statistics
3. Review reported content and apply appropriate actions:
   - Mark reports as under review, resolved, or dismissed
   - Apply timeouts (1 hour to 1 year) for rule violations
   - Apply permanent bans for severe violations (admin only)
4. Monitor restricted users and review moderation history
5. Use bulk actions for multiple reports when needed

## Security Features

- **Password Security**: Uses `password_hash()` with bcrypt
- **Session Security**: Secure cookies, HttpOnly, SameSite, and regeneration
- **CSRF Protection**: All forms include CSRF tokens
- **SQL Injection Prevention**: All queries use prepared statements
- **XSS Prevention**: All user input is properly escaped
- **Rate Limiting**: Login attempts, registration, and invite generation are limited
- **Input Validation**: Comprehensive server-side validation

## API Endpoints

### Messages API (`/api/messages.php`)

- `POST /api/messages.php?action=send` - Send a message
- `GET /api/messages.php?action=get_conversation&user_id=X` - Get conversation
- `GET /api/messages.php?action=get_conversations` - Get all conversations
- `POST /api/messages.php?action=mark_read` - Mark messages as read
- `GET /api/messages.php?action=search_users&q=query` - Search users

### Invites API (`/api/invites.php`)

- `POST /api/invites.php?action=generate` - Generate new invite code
- `GET /api/invites.php?action=list` - Get user's invite codes
- `GET /api/invites.php?action=validate&code=X` - Validate invite code
- `GET /api/invites.php?action=stats` - Get invite statistics

### Follow System API (`/follow.php`)

- `POST /follow.php?action=follow&user_id=X` - Follow a user
- `POST /follow.php?action=unfollow&user_id=X` - Unfollow a user
- `POST /follow.php?action=accept_follow&user_id=X` - Accept follow request
- `POST /follow.php?action=decline_follow&user_id=X` - Decline follow request
- `POST /follow.php?action=check_follow_status&user_id=X` - Check follow status
- `POST /follow.php?action=get_followers&user_id=X` - Get user's followers
- `POST /follow.php?action=get_following&user_id=X` - Get who user follows
- `POST /follow.php?action=get_follow_stats&user_id=X` - Get follow statistics

## Customization

### Customizing Appearance

Edit `css/dashboard.css` to modify the dashboard appearance or `style.css` for the login/registration pages.

### Database Configuration

Modify `config/database.php` to change database settings, session parameters, or security configurations.

### Database Schema

The platform includes the following key tables:

**Core Tables:**
- `users` - User accounts and authentication
- `invite_codes` - Invitation code management
- `messages` - Private messaging system

**Social Feature Tables:**
- `user_settings` - Privacy and presence settings
- `user_relationships` - Follow relationships and mutual connections
- `approved_messaging` - Approved messaging lists for restricted users
- `reports` - User reporting system
- `user_restrictions` - User timeouts, bans, and messaging restrictions

### User Roles

The system supports three roles:
- `admin`: Full system access and moderation capabilities
- `moderator`: Can moderate content and manage reports
- `user`: Standard user access with social features

## Troubleshooting

### Common Issues

1. **Database Connection Error**: Check your database credentials in `config/database.php`
2. **500 Internal Server Error**: Check PHP error logs and ensure all files have correct permissions
3. **Messages Not Sending**: Verify the API endpoints are accessible and check browser console for JavaScript errors
4. **Invite Codes Not Working**: Ensure the database tables were created correctly and check server time settings

### Error Logs

Check these locations for error information:
- PHP error log: `/var/log/php_errors.log` or your web server's error log
- MySQL error log: `/var/log/mysql/error.log`
- Web server error log: `/var/log/apache2/error.log` or `/var/log/nginx/error.log`
